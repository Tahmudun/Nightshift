# M6a — The Hunt: the reader exists, and there is something worth ranking

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development
> (recommended) or superpowers:executing-plans to implement this plan
> task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn Nightshift from a correct system holding three applicable roles
into one this reader opens in the morning: their own account, their own
confirmed resume, hundreds of real early-career postings, and a relocation flag
so the non-New-York ones can be filtered rather than discarded.

**Architecture:** An internship list is modelled as a **board with one token
and many employers**. `ingestion.py:296` calls `get_or_create_company` per job
from `NormalizedSourceJob.company_name`, so a multi-employer board needs zero
pipeline changes — the list adapter implements the existing `JobSourceAdapter`
Protocol and everything downstream (dedupe, `job_locations`, freshness,
scoring) works unchanged. `landmass` is a pure function of one `ParsedLocation`,
written at ingestion and backfilled.

**Tech Stack:** Python 3.12, FastAPI, Pydantic v2, SQLAlchemy 2.0 async,
Alembic, pytest, httpx via `PoliteClient` only.

**Spec:** `docs/architecture/the-hunt.md` (§5 is this plan). Also required:
`docs/architecture/archipelago.md` §4 and §6, whose designs this plan builds.

## Global Constraints

- **I1** — a list entry never produces `verified` confidence. Free text resolves
  through the existing normalizer only.
- **I2** — no `proposed_*` value is promoted without an explicit reader action.
- **I3** — a list that 404s, returns `[]`, or marks every entry `active: false`
  closes **zero** jobs. `active: false` is recorded, never acted on.
- **I5** — nothing in this slice submits an application.
- **I7** — both adapters ship with committed fixtures recorded from the real
  files, and the live path is the same code.
- **Naming** — `landmass`, never `region` (`scoring.py:195` owns `region`).
- **Time** — `TIMESTAMPTZ`, UTC in the database.
- **Migrations** — reversible and tested both directions.
- **Every adapter has committed fixture tests from recorded real payloads.**
- Run `make check` before every commit. Conventional commits, scoped.

```python
# services/api/nightshift/domain/landmass.py
"""Which landmass a location belongs to. One pure function, no I/O.

Written at ingestion and backfilled, never computed on read — a reader
filtering to New York is running a WHERE clause, and a Python property cannot
be indexed.
"""

from __future__ import annotations

from nightshift.db.base import Landmass
from nightshift.domain.locations import ParsedLocation


def landmass_for(location: ParsedLocation) -> Landmass:
    """Sort one parsed location into its landmass.

    Order matters and is the whole rule: a known city decides first, because
    what is known about *place* is the question. ``confidence`` does not
    appear — a role written "Remote — New York, NY" names a city, and sorting
    it offshore would discard a fact the posting stated.
    """
    if location.is_nyc:
        return Landmass.NEW_YORK
    if location.city is not None:
        return Landmass.ELSEWHERE_CITY
    if location.state is not None or location.country is not None:
        return Landmass.ELSEWHERE_BROAD
    return Landmass.UNPLACED
```

from __future__ import annotations

import uuid

from nightshift.db.base import Landmass, LocationConfidence
from nightshift.db.models import Job, JobLocation
from nightshift.domain.placement import placement_location


def _row(landmass: Landmass, raw_text: str, *, is_primary: bool) -> JobLocation:
    """An unattached JobLocation. `placement_location` is pure over `job.locations`,
    so this needs no session and no database."""
    return JobLocation(
        id=uuid.uuid4(),
        raw_text=raw_text,
        landmass=landmass,
        is_primary=is_primary,
        location_confidence=LocationConfidence.CITY_ONLY,
    )


def _job(*locations: JobLocation) -> Job:
    job = Job(id=uuid.uuid4(), title="Software Engineer Intern")
    job.locations = list(locations)
    return job


def _new_york(*, is_primary: bool = False) -> JobLocation:
    return _row(Landmass.NEW_YORK, "New York, NY", is_primary=is_primary)


def _london(*, is_primary: bool = False) -> JobLocation:
    return _row(Landmass.ELSEWHERE_CITY, "London, UK", is_primary=is_primary)


def _san_francisco(*, is_primary: bool = False) -> JobLocation:
    return _row(Landmass.ELSEWHERE_CITY, "San Francisco, CA", is_primary=is_primary)

    assert placement_location(job) is ny

    assert placement_location(job) is primary


def test_the_first_wins_when_nothing_is_primary() -> None:

honouring the `etag` argument. It must:
- return `ok=True, not_modified=True` on `304`, describing no postings;

from __future__ import annotations

import subprocess
import uuid
from pathlib import Path

import pytest
from sqlalchemy import text
from sqlalchemy.ext.asyncio import AsyncSession

from nightshift.config import get_settings


@pytest.mark.asyncio
async def test_a_backup_restores_the_readers_applications(
    db_session: AsyncSession, tmp_path: Path
) -> None:
    settings = get_settings()
    assert "nightshift_test" in settings.test_database_url, (
        "this test truncates; it must never point at the dev database"
    )

    marker = f"restored-{uuid.uuid4()}"
    await db_session.execute(
        text("INSERT INTO applications (id, user_id, job_id, stage, notes) "
             "VALUES (gen_random_uuid(), :user, :job, 'applied', :marker)"),
        {"user": ..., "job": ..., "marker": marker},
    )
    await db_session.commit()

    dump = tmp_path / "backup.sql"
    subprocess.run(["./scripts/backup.sh", str(dump)], check=True)
    assert dump.stat().st_size > 0

    await db_session.execute(text("TRUNCATE applications CASCADE"))
    await db_session.commit()
    gone = await db_session.execute(
        text("SELECT count(*) FROM applications WHERE notes = :m"), {"m": marker}
    )
    assert gone.scalar_one() == 0, "the truncate did not happen, so the restore proves nothing"

    subprocess.run(["./scripts/restore.sh", str(dump)], check=True)
    back = await db_session.execute(
        text("SELECT count(*) FROM applications WHERE notes = :m"), {"m": marker}
